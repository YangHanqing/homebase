Trusted ranges

One private CIDR or IP per line, at most 5. Overlay networks you assert are already encrypted (Tailscale, WireGuard, …).

Example: 100.64.0.0/10 (Tailscale), 192.168.0.0/16 (LAN)

Paired devices

Browsers that can reach Homebase from another device. Revoking logs that device out on the next request.

    No devices paired yet. Run homebase pair on this machine.

    Homebase uses unencrypted HTTP. When deployed on a regular LAN, other devices on the same network may perform a man-in-the-middle attack; security depends on whether that network is trusted. Prefer access via an already-encrypted network such as Tailscale or WireGuard.

    Revoke every paired device? They will need to run homebase pair again.
